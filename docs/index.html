One Mac, every output, tuned on its own.

UltraBass 9000 sends your system audio to as many devices as you pick, all at once. Each one gets its own volume, 5‑band EQ, filters, and delay. macOS's built-in Multi-Output Device sends the same signal to every output and can't shape or align any of them. This does both. No driver. No kernel extension.

Why no download

There's no downloadable build yet. That's on purpose: macOS only grants microphone access to signed builds. An unsigned download would launch fine and record nothing, which is worse than not shipping it at all. A signed release needs an Apple Developer ID, and that's not set up yet. Build it yourself for now. Xcode signs the app with your own developer identity when you hit Run, so the permission prompt shows up the way it's supposed to.

Features all built and working
Routing

Multi-output routing

Pick any number of outputs, and audio goes to all of them at once. No kernel extension, no separate driver.

Equalizer

Five-band EQ, per output

Three peak filters plus a low shelf and a high shelf. Drag the curve directly and the sound changes as you move it.

Filters

High-pass, low-pass, band-pass

Each one runs in series with that device's EQ, so the response curve on one output can look nothing like the next.

Delay

Delay compensation

Delay the faster devices so sound from every speaker lands at the same moment.

Auto-sync

Acoustic auto-sync

Plays a sweep through each device in turn and listens back on the built-in microphone. From that, it works out the alignment on its own. Measured on real hardware, it repeats to within ~0.2 ms.

How it works no kernel extension, no sudo
01

Tap

UltraBass 9000 copies the audio your Mac is already playing, right as it leaves each app, using a macOS process tap. Nothing gets muted. Every app keeps playing like normal.

ProcessTap.swift:28 ↗
02

Route

That copy feeds a private aggregate device, built behind the scenes and wired to whichever outputs you picked. It only exists while UltraBass 9000 is running.

03

Shape

Each output gets its own path: delay, then EQ, then filters, before the sound reaches that speaker. Every device ends up tuned on purpose, instead of playing the same signal as the rest.
